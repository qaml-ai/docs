Every endpoint requires a live camelStream API key. Both header styles accept
keys beginning with `qaml_live_`.

<CardGroup cols={2}>
  <Card title="Bearer token" icon="lock">
    OpenAI clients normally send `Authorization: Bearer $CAMEL_API_KEY`.
  </Card>
  <Card title="API key header" icon="lock">
    Anthropic clients normally send `x-api-key: $CAMEL_API_KEY`.
  </Card>
</CardGroup>

<Warning>
  Never expose a key in browser code, commit it to a repository, or include it
  in a public log. Revoked keys stop working immediately.
</Warning>

## Programmatic key provisioning

Management API keys begin with `qaml_mgmt_` and are separate from inference
keys. They can create and revoke `qaml_live_` keys but cannot run inference.
See the [Management API guide](/stream/management-api) to provision keys from
your backend.
