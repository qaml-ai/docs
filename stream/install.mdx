camelStream is the model. Your coding agent stays the same and sends its
requests to Stream instead of OpenAI or Anthropic. The installer does that
setup for you.

```bash Terminal
curl -fsSL https://stream.camelai.com/install | bash
```

You need a key from [the Stream console](https://stream.camelai.com/console)
and one of these agents installed: Claude Code, Codex, OpenCode, Pi, Hermes,
or OpenClaw.

The installer finds the agents on your machine, asks for your key, checks it,
writes each agent's configuration, and sends one test request. It backs up
any file it changes and is safe to run again.

## Start your agent

Open a new terminal, then:

| Agent | Command |
| --- | --- |
| Claude Code | `claude` |
| Codex | `codex --profile camel-stream` |
| OpenCode | `opencode` |
| Pi | `pi` |
| Hermes | `hermes chat` |
| OpenClaw | `openclaw gateway restart` |

<Tip>
  If an agent reports an auth error, open a new terminal first. The key is
  loaded by your shell from `~/.camelstream/env.sh`.
</Tip>

## Scripted use

Set `CAMEL_API_KEY` and name the agents to skip the prompts:

```bash Terminal
CAMEL_API_KEY="qaml_live_..." curl -fsSL https://stream.camelai.com/install | bash -s -- --agents codex,claude
```

Run it with `--help` for all options.

## Manual setup

The [per-agent guides](/stream/agents) show the same configuration if you
