<Tip>
  Setting up a coding agent? Run the [installer](/stream/install) instead.
  It creates the configuration and sends the first request for you.

  ```bash Terminal
  curl -fsSL https://stream.camelai.com/install | bash
  ```
</Tip>

<Steps>
  <Step title="Create a key">
    Generate an API key in [the Stream console](https://stream.camelai.com/console).
    It is only shown once.
  </Step>

  <Step title="Set the key">
    Keep the key in an environment variable instead of source control.

    ```bash Terminal
    export CAMEL_API_KEY="qaml_live_..."
    ```
  </Step>

  <Step title="Send a request">
    Use any supported format. Streaming responses use server-sent events.

    ```bash First request
    curl --no-buffer https://stream.camelai.com/v1/chat/completions \
      -H "Authorization: Bearer $CAMEL_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "auto",
        "messages": [
          {"role": "user", "content": "Write a haiku about distributed systems."}
        ],
        "stream": true
      }'
    ```
  </Step>
</Steps>
