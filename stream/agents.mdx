Camel Stream is an OpenAI- and Anthropic-compatible endpoint. These agents
do not need a Camel Stream plugin. Install the agent, add a Stream key, and
paste a provider block.

| | |
| --- | --- |
| **Model** | `deepseek-v4-flash` |
| **OpenAI base URL** | `https://stream.camelai.com/v1` |
| **Anthropic base URL** | `https://stream.camelai.com` |
| **Key** | `CAMEL_API_KEY` |
| **Context window** | 256k input tokens |

Create a key in [the Stream console](https://stream.camelai.com/console)
before you start. It is shown once.

<CardGroup cols={2}>
  <Card title="Hermes Agent" icon="robot" href="/stream/hermes">
    `hermes model` or a `custom_providers` block.
  </Card>
  <Card title="OpenClaw" icon="robot" href="/stream/openclaw">
    Add a `models.providers` entry in `openclaw.json`.
  </Card>
  <Card title="Claude Code" icon="terminal" href="/stream/claude-code">
    Set `ANTHROPIC_BASE_URL` to Stream's Messages API.
  </Card>
  <Card title="Codex" icon="code" href="/stream/codex">
    Add a named Responses provider in `~/.codex`.
  </Card>
  <Card title="OpenCode" icon="folder-open" href="/stream/opencode">
    Register Camel Stream in `opencode.json`.
  </Card>
  <Card title="Pi" icon="microchip" href="/stream/pi">
    Add a provider to `~/.pi/agent/models.json`.
  </Card>
</CardGroup>

<Note>
  These are third-party agents. Camel Stream provides the model. Keep the
  key in an environment variable or the agent's secret file, not in a git
  repo.
</Note>
