Create a key in [the Stream console](https://stream.camelai.com/console),
then run the installer. It detects the agents on your machine, writes the
configuration below, and sends one request to confirm it works.

```bash Terminal
curl -fsSL https://stream.camelai.com/install | bash
```

The guides on this page are the manual equivalent. No camelStream plugin is
required either way. Every guide uses the same model ID, `auto`; the model
serving your stream comes from [the fleet](/stream/fleet). See the
[installer page](/stream/install) for what it changes and how to undo it.

| | |
| --- | --- |
| **Model ID** | `auto` |
| **OpenAI base URL** | `https://stream.camelai.com/v1` |
| **Anthropic base URL** | `https://stream.camelai.com` |
| **Key** | `CAMEL_API_KEY` |
| **Context window** | 260K tokens guaranteed (see [the fleet](/stream/fleet)) |

<CardGroup cols={2}>
  <Card title="Hermes Agent" href="/stream/hermes">
    `hermes model`, then pick Custom endpoint.
  </Card>
  <Card title="OpenClaw" href="/stream/openclaw">
    Add a `models.providers` entry and restart the gateway.
  </Card>
  <Card title="Claude Code" href="/stream/claude-code">
    Set the Anthropic gateway and map model aliases to `auto`.
  </Card>
  <Card title="Codex" href="/stream/codex">
    Add a named Responses profile in `~/.codex`.
  </Card>
  <Card title="OpenCode" href="/stream/opencode">
    `/connect`, choose Other, then select the model.
  </Card>
  <Card title="Pi" href="/stream/pi">
    Add a provider in `~/.pi/agent/models.json`.
  </Card>
</CardGroup>

<Note>
  These are third-party agents. camelStream provides the model. Keep the
  key in an environment variable or the agent's secret file, not in a git
  repo. Requests beyond your concurrent stream allowance
  [queue instead of failing](/stream/queues-and-errors). Set up before the
  `auto` model ID existed? Your existing config keeps working; see the
  [fleet page FAQ](/stream/fleet#common-questions) for how the legacy ID is handled.
</Note>
