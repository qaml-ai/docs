[Claude Code](https://code.claude.com/docs) can send Anthropic Messages
traffic to a gateway. Camel Stream speaks that protocol.

| | |
| --- | --- |
| **Base URL** | `https://stream.camelai.com` |
| **Model** | `deepseek-v4-flash` |
| **Auth** | `ANTHROPIC_AUTH_TOKEN` |
| **Context window** | 256k input tokens |

<Warning>
  Claude Code's Stream endpoint has **no** `/v1`. Use
  `https://stream.camelai.com`, not `https://stream.camelai.com/v1`.
  Set `ANTHROPIC_API_KEY` to an empty string so Claude Code does not keep
  using a previous Anthropic login.
</Warning>

<Note>
  Anthropic documents LLM gateways but does not endorse routing Claude Code
  to non-Claude models. This setup is Claude Code compatible, not
  Anthropic-endorsed. See
  [Connect Claude Code to an LLM gateway](https://code.claude.com/docs/en/llm-gateway-connect).
</Note>

## 1. Install Claude Code

```bash Terminal
curl -fsSL https://claude.ai/install.sh | bash
```

Or:

```bash Terminal
npm install -g @anthropic-ai/claude-code
```

## 2. Create a Stream key

Generate an API key in [the Stream console](https://stream.camelai.com/console).
It is shown once.

## 3. Point Claude Code at Stream

Add this to `~/.zshrc` or `~/.bashrc`, then reload your shell:

```bash Terminal
export CAMEL_API_KEY="qaml_live_..."
export ANTHROPIC_BASE_URL="https://stream.camelai.com"
export ANTHROPIC_AUTH_TOKEN="$CAMEL_API_KEY"
export ANTHROPIC_API_KEY=""
export CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY="1"
```

```bash Terminal
source ~/.zshrc
```

If you previously logged into Anthropic inside Claude Code, run `/logout`
first.

To persist the same settings without exporting them every session, merge
this into user-level `~/.claude/settings.json`:

```json ~/.claude/settings.json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://stream.camelai.com",
    "ANTHROPIC_AUTH_TOKEN": "qaml_live_...",
    "ANTHROPIC_API_KEY": "",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1"
  }
}
```

Do not put the key in a project `.claude` file or a git repo.

## 4. Verify

```bash Terminal
cd /path/to/your/project
claude
```

Inside Claude Code:

```text
/status
```

You should see:

```text
Auth token: ANTHROPIC_AUTH_TOKEN
Anthropic base URL: https://stream.camelai.com
```

Then run `/model` and choose `deepseek-v4-flash`. Gateway discovery reads
Stream's `/v1/models` endpoint.

<Note>
  Camel Stream queues requests when every subscribed stream is busy. Claude
  Code should keep the HTTP connection open. See
  [Queues & errors](/stream/queues-and-errors).
</Note>
