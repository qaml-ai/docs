<Warning>
  **camelStream is shutting down.** These legacy docs are kept for existing
  customers. New subscriptions and renewals are closed. API access ends with
  your current paid period. [Check your end date and invoices in Settings](https://stream.camelai.com/settings).
  Move connected coding agents to another provider before your access ends.
</Warning>

camelStream is camelAI's inference API, with OpenAI Chat Completions, OpenAI
Responses, and Anthropic Messages compatibility. These pages preserve the
setup guides and API reference for customers finishing their paid service period.

## What happens to your subscription

We're no longer able to subsidize the token costs behind camelStream, so we're
winding it down. Your subscription will not renew, and you do not need to cancel
it yourself. New subscriptions and changes to stream counts are closed.

Your service continues through the end of your current paid billing period.
After that, your API keys stop working. [Sign in to Stream Settings](https://stream.camelai.com/settings)
to see your account's end date and view your invoices. Switch connected coding
agents and applications to another provider before that date. If you used our
installer, see [how to remove its configuration](/stream/install#removing-it).

For questions, email [support@camelai.com](mailto:support@camelai.com).

## API reference for existing customers

| | |
| --- | --- |
| **Base URL** | `https://stream.camelai.com/v1` |
| **Model ID** | `auto` |

The model ID `auto` means your request is served by whatever fleet model is
available. See [the fleet](/stream/fleet).
