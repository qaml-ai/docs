camelStream provides one endpoint with OpenAI Chat Completions, OpenAI
Responses, and Anthropic Messages compatibility, serving unlimited frontier
intelligence from [a fleet of models](/stream/fleet) above a published
intelligence floor. Requests beyond your concurrent stream allowance queue
automatically instead of failing.

## How pricing works

A subscription covers the number of concurrent streams you choose, from 1 to
50, at a flat monthly price per stream. Tokens are unlimited while the
subscription is active, and you can cancel anytime. Change your stream count
in [Stream Settings](https://stream.camelai.com/settings); Stripe prorates the
change for the current billing period. See
[stream.camelai.com](https://stream.camelai.com) for current pricing, and
[contact us](https://camelai.com/stream/contact) if you need more than 50
streams.

| | |
| --- | --- |
| **Base URL** | `https://stream.camelai.com/v1` |
| **Model ID** | `auto` |

The model ID `auto` means your request is served by whatever fleet model is
available. See [the fleet](/stream/fleet).
