<Note>
  Camel Stream is separate from the [camelAI coding agent](/getting-started/overview).
  This tab documents the inference API only.
</Note>

Camel Stream provides one DeepSeek endpoint with OpenAI Chat Completions,
OpenAI Responses, and Anthropic Messages compatibility. Requests beyond your
concurrent stream allowance queue automatically instead of failing.

## How pricing works

Each subscription adds one concurrent stream for a flat monthly price. Use
unlimited tokens while your subscription is active, and cancel anytime. See
[stream.camelai.com](https://stream.camelai.com) for current pricing.

| | |
| --- | --- |
| **Base URL** | `https://stream.camelai.com/v1` |
| **Model** | `deepseek-v4-flash` |
