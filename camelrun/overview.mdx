camelRun is camelAI's hosted agent runtime. You define an agent's tools in your
own code with the TypeScript or Python SDK, or serve them over HTTP. camelRun
runs the model loop, keeps each agent's history and files, compacts long
conversations, runs model-written code in a sandbox, and wakes agents when there
is work. Most agents are asleep at any moment and cost nothing while they are.

```ts
import { Agents } from "@camelai/run";

const agents = new Agents(); // reads CAMELAI_API_KEY
const agent = await agents.upsert("support-triage", {
  instructions: "Be concise.",
});
console.log((await agent.run("Which tickets look urgent?")).text);
await agents.close();
```

## Connect your coding agent

The hosted MCP server at `https://run.camelai.com/mcp` needs no API key: sign
in with GitHub or Google when your client asks, which creates your account.
GitHub accounts older than 30 days start with free credit; everyone else
verifies a card on the [Billing](https://run.camelai.com/console/billing) page
(no charge).

<Tabs>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http camelrun https://run.camelai.com/mcp
    # Then run /mcp in Claude Code to sign in. Or skip signing in with a key:
    claude mcp add --transport http camelrun https://run.camelai.com/mcp --header "Authorization: Bearer art_..."
    ```
  </Tab>
  <Tab title="Codex">
    ```bash
    codex mcp add camelrun --url https://run.camelai.com/mcp
    codex mcp login camelrun
    ```
  </Tab>
  <Tab title="Cursor">
    <a href="cursor://anysphere.cursor-deeplink/mcp/install?name=camelrun&config=eyJ1cmwiOiJodHRwczovL3J1bi5jYW1lbGFpLmNvbS9tY3AifQ==">Add camelRun to Cursor</a>,
    or add it to `.cursor/mcp.json`:

    ```json
    { "mcpServers": { "camelrun": { "url": "https://run.camelai.com/mcp" } } }
    ```
  </Tab>
  <Tab title="VS Code">

    then **Add custom connector**, and enter
    `https://run.camelai.com/mcp`.
  </Tab>
</Tabs>

## What you get

<CardGroup cols={2}>
  <Card title="Durable, keyed agents" icon="database">
    The same key is the same agent, with its history and files, from any
    process, until you delete it.
  </Card>
  <Card title="Tools in your code" icon="wrench">
    Tools run in your process or on your HTTPS endpoint, with your credentials.
    MCP servers and OpenAPI specs work too.
  </Card>
  <Card title="People in the loop" icon="user-check">
    Approvals, questions and forms suspend a run for days, then resume it where
    it stopped.
  </Card>
  <Card title="Chat UI in minutes" icon="messages-square">
    React, Vue, Svelte and Solid components stream an agent into your app
    without exposing your API key.
  </Card>
  <Card title="Channels" icon="plug">
    Slack, Telegram, Discord, GitHub and any service that sends
    webhooks can start and talk to agents.
  </Card>
  <Card title="Agents as MCP servers" icon="plug-zap" href="/camelrun/mcp-server">
    Every agent is an MCP server, so Claude, Cursor or any MCP client can
    message it.
  </Card>
  <Card title="Any model" icon="brain">
    Pick from the catalog, bring your own provider keys, or add a model server
    of your own.
  </Card>
</CardGroup>
